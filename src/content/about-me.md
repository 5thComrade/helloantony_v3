## Neeve.ai

### About Neeve.ai

Neeve.ai is a network security company that provides **zero-trust remote access to OT devices and endpoints**.

Neeve's technology enables users to securely access devices located within building and operational networks without requiring those devices to be directly exposed to the public internet.

A core part of this architecture involves a physical node deployed within a building's network. The node connects the building's network to Neeve's secure cloud infrastructure, enabling authorized users to securely access devices on the network.

## Neeve Portal

### Overview

**Neeve Portal** is a greenfield platform that Antony helped lead and build at Neeve.ai.

The goal of Neeve Portal was to bring together the capabilities of Neeve's two existing applications — **Secure Edge (SE)** and **Remote Access (RA)** — into a single modern platform.

The new platform is commonly referred to as **SERA**, representing the combination of Secure Edge and Remote Access.

Neeve Portal combines the strongest capabilities of the legacy applications while introducing a significantly upgraded user experience and modern enterprise capabilities.

### Secure Edge

**Secure Edge (SE)** was primarily used by OT and building administrators to configure and manage the physical Neeve node deployed within a building's network.

The physical node is an important component of Neeve's remote-access architecture. It is connected to the building's network and communicates with Neeve's secure cloud infrastructure.

This connection makes it possible for authorized users to securely access devices within the building's network.

### Remote Access

**Remote Access (RA)** was designed for individual users who needed to access specific devices on a building's network.

Typical users could require access to devices to perform day-to-day operational tasks, maintenance, upgrades, and other activities.

### Combining Secure Edge and Remote Access

Neeve Portal brings the functionality of Secure Edge and Remote Access together into a unified platform.

Instead of requiring users to work across separate legacy applications, Neeve Portal provides a single experience for managing access, users, devices, and other capabilities.

The platform also introduces several improvements and enterprise-focused capabilities, including:

- Upgraded user experience
- Unified platform experience
- User management
- Single Sign-On (SSO)
- Enterprise-oriented functionality
- Modernized application architecture
- Shared design system and UI components

Antony was the lead responsible for building the greenfield Neeve Portal application.
